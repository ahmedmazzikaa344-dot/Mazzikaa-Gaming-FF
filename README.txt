MAZZIKAA GAMING FF — Front-end package
========================================
Open index.html in a browser to preview the storefront.

Important:
- This is a front-end preview, not a deployed live store.
- Product price editing uses browser LocalStorage only.
- Order submission only creates a local order summary; it does not send orders to an admin.
- Admin preview PIN in this prototype is 2468 and is NOT secure.
- Before taking real orders, connect a backend/database, secure admin authentication, order records,
  verified payment workflow, and hosting/domain.
- Prices included are the prices provided in the planning conversation and should be confirmed.
